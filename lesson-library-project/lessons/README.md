# Add your HTML lessons here

Copy your original `.html` lesson files into this folder. You can put them directly here or arrange them in subfolders.

The app scans file names only when generating the catalog. It does not parse or rewrite lesson content.

For your current collection, copy the 16 original HTML files listed in the project's main README into this folder. Keep any companion images, stylesheets, scripts, fonts, and other assets in their original relative locations so the lessons continue to work.
