1ما هي الـ Dunder Methods؟

2__str__ مقابل __repr__

__str__ للمستخدم النهائي (يُستدعى عند print)، و__repr__ للمطور وللـ Debugging. إن غاب __str__ تستعمل Python الدالة __repr__ كبديل.
